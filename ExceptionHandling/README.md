EXCEPTION HANDLING:-

Exceptions are run time errors.

Errors->are mainly two types 1.compile-time error 2.run-time error

In the world of programming,"the time refers to when computer discovers the error"

Compile-time errors(syntax errors):
             who identifies->compiler(a tool which translates code into machine code)
             when->before program ever starts executing.
             cause->breaking grammar rules of a language.
             result->can not generate executable file.

Run-time errors(Exceptions):
             who identifies->cpu,os,VM
             when->while the user is interacting with the program.
             cause->Impossible opeartions or external failures
             result->program crashes(ends abruptly),unless uses exception handling.
             examples:DivisionByZero,memory out of range,file not found etc
